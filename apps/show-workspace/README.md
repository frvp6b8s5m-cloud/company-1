# BZaudio Show Workspace

**Hostname target:** `shows.bzaudio.com`  
**Status:** functional local production-sheet prototype; not yet deployed.

## Current features

- Enter production, venue, date and stage/room details.
- Add and remove stage input-list entries with mic/DI and notes.
- Add production notes.
- Save show details, input lists and production notes automatically in this browser.
- Import and validate a versioned JSON show sheet; clear local data.
- Export a portable local JSON show sheet.

## Next phases

Stage plot editing, equipment references, attachments, revisions, console backups and deeper SystemOS handoff remain future work. Cloud sharing requires a selected backend, secure authentication, authorization, backups and user-controlled data export/deletion.

No account or cloud storage is implemented.
