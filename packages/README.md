# Shared BZaudio packages

Reusable, versioned contracts and design foundations live here.

Planned packages:
- `contracts/`: schemas and validators for equipment, compatibility assertions, system designs and show-project exchange.
- `design-system/`: shared tokens, typography, interaction patterns and accessible components.
- `app-shell/`: cross-product navigation and product identity conventions, once app frameworks are selected.

Keep packages framework-neutral where practical. Avoid premature framework coupling. Shared package changes must trigger dependent application tests.
