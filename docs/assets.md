# Asset Provenance and Rights Ledger

Production imagery must be authentic real-world photography of professional audio equipment, venues, studios, installation work or architecture. No AI-generated imagery or synthetic sci-fi artwork.

## Publishing rules
- Use only assets with a clear commercial-use license or written permission suitable for this website.
- Verify the license terms and download/source page at the time the asset is selected.
- Keep the original source URL, creator/photographer, license name, license URL or permission record, download date, asset filename, dimensions and optimization derivatives in this private project ledger.
- Do not publish attribution/source labels on the website unless the license requires visible attribution or the user later requests it. License-required attribution always takes precedence.
- Never assume that a search result, social post, manufacturer product page or image URL grants reuse rights.
- Manufacturer product images require applicable permission or terms that allow the intended commercial display.
- Optimize responsive derivatives and preserve a high-quality source copy outside the public asset path where appropriate.

## Review gate
An image is not production-ready until its rights are documented and its visual content is checked for authenticity, accuracy and relevance.

## Current implementation note
The first implementation uses responsive Pexels CDN image variants to establish the photographic art direction. Before production release, download and optimize approved copies into the repository (or verify stable CDN delivery), inspect each image at full resolution for logos/identifiable people/property rights, and update the ledger with final local paths and derivative dimensions. No visible credit labels are planned because the Pexels license does not require attribution; any separate rights or license requirement takes precedence.
