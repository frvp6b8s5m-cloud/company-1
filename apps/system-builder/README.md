# BZaudio System Builder

**Hostname:** `build.bzaudio.com`  
**Status:** scaffold only; not yet a working system-design application.

## Intended user journey

1. Describe the venue, application, audience and intended use.
2. Choose system components by role: console, stage I/O, microphones, speakers, subs, amplification, cabling, networking and accessories.
3. Review missing components, signal flow, power/network constraints and known dependencies.
4. Check each selected combination against Compatibility Center.
5. Save/export a system design and quote-ready bill of materials.

## Product requirements

- Do not recommend products solely from popularity; explain fit and assumptions.
- Distinguish verified specifications from missing or estimated data.
- Do not invent prices, inventory, coverage, SPL, impedance compatibility or power requirements.
- Show unresolved issues before quote handoff.
- Keep quote requests as the initial commercial workflow; no checkout.
- Acoustic prediction is a separate engineering milestone and must not be implied by a simple equipment picker.
