# BZaudio System Builder

**Hostname target:** `build.bzaudio.com`  
**Status:** functional local equipment-list prototype; not yet deployed.

## Current features

- Add equipment by category, make/model or description, and quantity.
- Review the draft equipment list, edit quantities and remove entries.
- Save the named plan automatically in this browser.
- Import and validate a versioned plan JSON backup; clear local data.
- See basic planning prompts for missing mixer/main-speaker categories.
- Export a local JSON system plan.

## Limitations

This is not yet a product catalog, price/inventory system, acoustic prediction engine, or validated compatibility checker. Planning prompts are not engineering conclusions. Product recommendations, power/impedance checks, coverage/SPL calculations and quote integrations require verified data and separate tests.

No account, cloud storage, product catalog, acoustic engine, compatibility engine or checkout is implemented. The local plan is a planning aid, not an engineering sign-off.
